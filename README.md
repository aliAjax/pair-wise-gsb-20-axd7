# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库 · 视野拼接与测量复核台

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- **扫描批次绑定**：每次扫描绑定样本、物镜倍率、标定版本与载物台偏移
- **视野拼接去重**：相邻视野重叠区内同一结构只生成一个编号，保留全部来源视野/批次
- **双人测量复核**：两名观察员对同一结构的测量并列保留，自动列出长度偏差与中心偏移；后到数据不覆盖已确认测量
- **标定版本管理**：标定更新后未确认测量立即失效并按新标定重算；已确认测量保留原标定与尺寸
- **中断恢复导入**：从完整扫描批次接续，只补未完成视野，重放不新增结构（幂等）
- **待核机制**：旧记录缺标定版本或载物台偏移时先标记待核，待核记录不能确认
- **导出**：样本详情与测量列表均含拼接来源与复核状态

## 目录

- `src/domain/types.ts` — 领域模型
- `src/domain/engine.ts` — 拼接去重、复核、标定重算、断点恢复、导出（纯函数）
- `src/data/seed.ts` — 演示数据（含重叠区、中断批次、旧待核记录）
- `src/App.tsx` — 样本详情 / 测量复核 / 标定与导入 / 导出 四个工作台
