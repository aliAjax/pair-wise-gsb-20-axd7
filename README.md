# hxwl-06 显微镜玻片观察 · 视野拼接与测量复核台

多倍率玻片扫描的视野拼接、结构编号去重、双观察员测量复核与标定版本管理。

## 技术栈

React 19 + Vite + TypeScript + CSS；规则引擎为纯函数，Vitest 自检。

## 本地运行

```bash
npm install
npm run dev      # 开发端口 5106
npm test         # 业务规则自检（9 项）
npm run build    # 生产构建
```

## 核心业务规则

1. **扫描绑定**：每个扫描批次创建时绑定样本、物镜倍率、标定版本与载物台偏移；标定必须与倍率匹配。
2. **重叠区单一编号**：同一物理结构在相邻视野（含 20% 重叠区）重复检出时合并为同一结构编号，坐标按多次检出均值融合，保留全部拼接来源视野。
3. **双观察员复核**：同一结构保留前两名观察员各自的坐标与尺寸（两份并列），自动列出坐标偏差（μm）与尺寸偏差（%），超阈值标记需复核；第三份起登记备查。
4. **确认不可覆盖**：教师确认后尺寸与原标定版本锁定；之后补交的坐标只登记为“确认后备查”，不改变确认结果。
5. **标定版本化**：发布新标定后，同倍率下所有**未确认**测量立即失效并按新系数重算（保留重算轨迹）；**已确认**测量保留原标定与尺寸，仅提示存在新版本；**待核**旧记录挂起不受影响。
6. **断点恢复（幂等）**：导入中断后批次完整保留规划；恢复时只补未完成视野，确定性重放拼接过程，已完成视野跳过，重放不新增任何结构（结果与一次性导入逐结构一致）。
7. **旧记录待核**：缺少标定版本或载物台偏移的旧记录一律置“待核”，禁止提交测量；补录标定与偏移后才进入测量流程。
8. **全程可追溯**：样本详情、测量列表、结构详情与 CSV 导出均显示拼接来源视野、重叠合并标记、复核状态、当前/确认标定与重算提示；所有规则触发写入审计日志。

## 目录

```
src/types.ts       领域模型
src/engine.ts      规则引擎（批次/拼接/复核/标定/恢复/旧记录/导出）
src/selfcheck.ts   规则自检（界面按钮与 Vitest 共用）
src/seed.ts        预置演示数据（覆盖全部规则场景）
src/components.tsx  批次网格、测量表、复核详情、标定面板、日志等
src/App.tsx        交互编排
```

## 演示数据场景

- 批次1（洋葱 40x，2×2）：导入 2 视野后中断 → 恢复补导完成 → 双观察员提交 → 1 个结构确认锁定（含第三人确认后补交）→ 发布 40x-v2 后 7 个未确认件重算、确认件锁定 v1。
- 批次2（血涂片 100x，1/2 视野已中断）待恢复，验证只补未完成与重放幂等。
- 3 条旧记录：2 条保持待核（缺标定/偏移），1 条已补录进入测量流程。
